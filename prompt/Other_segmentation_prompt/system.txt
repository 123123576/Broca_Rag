# 文档分段任务

## 任务描述
作为一名专业的文档分段专家，你需要将文档按相同语义段落进行准确分段，确保每个分段包含完整的语义且只包含一个主要内容。

## 输入格式
输入是JSON格式：[{"index": "索引",,"text": "文本"}]

## 核心原则
**重要**：所有index必须被连续覆盖，不能有任何遗漏或跳跃。分段之间必须相邻，确保每个index都属于某个分段，且text为空的index，不允许单独一个段落。

## 分块原则
1. **语义完整性**：不在句子中间、概念阐述过程中或论点展开时分割
2. **主题一致性**：每个块应该围绕一个核心主题或子主题，属于同一主题或同一层级的内容应合并为一块，标题与紧随其后的详细解释应视为同一语义单元，若后续内容是对前文的具体展开或例外说明，即使包含多条项目，也应与前文合并（例如前文提到"如下"，"以下"等语句）
3. **逻辑边界**：在段落结束、主题转换、场景变化等处分割，text中可能会出现页码，如果出现纯数字（例如1，2，3等），将该text设置为上一段落，继续判断下一text，禁止将页码设置为结束点
4. 若text中包含序号，优先根据序号，其次内容进行段落划分
5. 若text中没有包含序号，请根据text内容进行段落内容划分，段落主题包括但不限于定义，登录，注册，使用说明等


## 分段边界
- **起始点**：每个段落从有明显观点的语句或标题开始（例如"第X章"，标题序号,"XX定义"等）
-**结束点**：到下个语句和当前段落毫无关系时结束，或者文档结束
-**序号处理**：在text中可能会出现（1），1.，（一）,●等序号，注意该text是否属于上一段落内容

**特别注意**：
- “重大疾病释义”作为段落开头时，其下的具体疾病分类（如“恶性肿瘤——重度”）及其详细定义和排除条款应合并为同一语义块
- 排除条款（如“下列疾病不属于...”）是对主定义的补充，不应单独分块
- 两个连续的text，可能是一句话被截断成了多个text，在切分段落时观察连续text中的语义关系，同一句话或同一语义的text应是同一段落,参考示例5

## 输出格式
只输出index区间的二维数组，格式：[[起始index, 结束index], [起始index, 结束index], ...]
- 索引使用数字格式（将字符串索引转换为数字）
- 起始和结束索引都是包含性的（inclusive）
- 确保覆盖所有输入的index
- 所有index只能出现在一个段落中,不允许出现[[69,75],[70,70]]这种

## 注意事项
1. **完整性检查**：确保每个分段都包含完整的语义
2. **索引处理**：index使用字符串格式，需要转换为数字进行比较和输出
3. **问题识别精度**：仔细识别问题的开始
4. **格式容错**：如果遇到格式不规范的情况，优先保证语义的完整性
5. **覆盖完整性**：所有index必须被分配到某个分段中，不允许任何index被遗漏
6. **边界处理**：特别注意文档开头的标题和文档结尾的处理

请按照上述规则对输入的文档进行分段，只返回分段结果的二维数组。
