# 文档分段任务

## 任务描述
作为一名专业的文档分段专家，你需要将文档按分块原则进行准确分段，确保每个分段包含完整的语义且只包含一个主要内容。

## 输入格式
输入是JSON格式：[{"index": "索引",,"text": "文本"}]

## 核心原则
**重要**：所有index必须被连续覆盖，不能有任何遗漏或跳跃。分段之间必须相邻，确保每个index都属于某个分段。

## 分块原则
1. **标题序号**：若text中出现标题序号，可参考标题序号进行段落划分，例如"第一章XXX"，可根据"XXX"去进行主题总结，把该章节的内容全部组合成一个段落。执行第二步，观察段落最后一句话是否是完整语句。参考示例3的输入输出
2. **语句完整性**：相邻的text，优先判断是否是同一语句被切分成了多个text，同一语句必须在同一段落。例如text1是"所有",该text中的最后一个字符不是标点符号，即不是一个完整的语句，判断下一text是否和该text为同一语句，属于同一段落，参考示例一的输入输出。
3. **段落完整性**：text中出现了以下，如下等提及下文的词语，判断下文text是否与当前段落属于同一段落，参考示例1的输入输出。

## 分段边界
- **起始点**：每个段落从有明显观点的语句或标题开始（例如"第X章"，标题序号等），"第X章"一定是段落起始点，不允许在段落中间
- **结束点**：到下个语句和当前段落毫无关系时结束，或者文档结束，不能以"第X章"标题结尾

## 段落组成
1. 章节标题 + 该章节的详解
2. 纯文本

## 输出格式
只输出index区间的二维数组，格式：[[起始index, 结束index], [起始index, 结束index], ...]
- 索引使用数字格式（将字符串索引转换为数字）
- 起始和结束索引都是包含性的（inclusive）
- 确保覆盖所有输入的index
- 所有index只能出现在一个段落中,不允许出现[[69,75],[70,70]]这种

### 示例1（text中出现如下，以下等词时，注意下文是否是该主题的详解）
**输入：**
文档名称：渣打银行（中国）有限公司信用卡章程-12513.docx.json_processed.json
[
    {
        "index": "13",
        "text": "1. 除非在本章程中另有定义或根据上下文另有解释，本章程涉及的下列名词遵从如下定义："
    },
    {
        "index": "14",
        "text": "“发卡行”指渣打银行（中国）有限公司，包括其继受者及受让者。"
    },
    {
        "index": "15",
        "text": "“客户”指向发卡行申请信用卡（包括主卡和附属卡）的申请人及/或获得卡片核发的持卡人，依上下文确"
    },
    {
        "index": "16",
        "text": "定其具体含义，包括主卡客户和附属卡客户。"
    }]

**输出：** `[[13，16]]`

### 示例2（text中最后一个字符不是标点符号，判断下一text是否和当前text属于同一语句）
**输入：**
文档名称：渣打银行（中国）有限公司信用卡章程-12513.docx.json_processed.json
[
    {
        "index": "31",
        "text": "“预借现金”亦称取现，是指在客户未预先在信用卡中存入现金的情况下，可在发卡行核定的预借现金额"
    },
    {
        "index": "32",
        "text": "度范围之内提取人民币或当地货币的服务。"
    }]

**输出：** `[[31，32]]`

### 示例3
**输入：**
文档名称：XXX.pdf.json_processed.json
[
    {
        "index": "14",
        "text": "| 第一章 | 保障方案 |"
    },
    {
        "index": "15",
        "text": "一、保险期间"
    },
    {
        "index": "16",
        "text": "整体服务期限为两年，首年度保险期间：2023 年5 月1 日0 时起至2024"
    },
    {
        "index": "17",
        "text": "年4 月30 日24 时止。"
    },
    {
        "index": "18",
        "text": "| 第二章 | 保障方案 |"
    }]

**输出：** `[[14，17],[18，18]]`

请按照上述规则对输入的文档进行分段，只返回分段结果的二维数组。
