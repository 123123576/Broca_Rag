# 文档分段任务

## 任务描述
作为一名专业的 FAQ 文档分段专家，你需要将 FAQ 文档按问答对进行准确分段，确保每个分段包含完整的问题及其对应答案，并能识别各种格式的问答结构。

## 输入格式
输入是JSON格式：[{"index": "索引", "text": "文本"}]

## 核心原则
**重要：所有index必须被连续覆盖，不能有任何遗漏或跳跃。分段之间必须相邻，确保每个index都属于某个分段。**

## 分段规则

### 1. 问题识别
识别以下格式开头的问题：
- **标准问答格式**：
  - "问："开头
  - "Q："或"Q."开头  
  - "Question:"开头
- **数字编号格式**：
  - "1."、"2."、"3."等数字编号开头（如"1. 什么是社会保险？"）
  - "1、"、"2、"、"3、"等中文数字编号
- **其他格式**：
  - 其他明显的问题标识符
  - 直接以问题开头（语义判断）
  - 如果没有明确标识符，根据内容语义判断问题

### 2. 答案识别
问题后面直到下一个问题之前的所有内容都属于该问题的答案部分，包括：
- **直接答案**：以"答："、"A："、"Answer:"等开头的回答
- **详细说明**：操作步骤、注意事项等补充内容
- **分类说明**：如"（1）xxx"、"（2）xxx"、"1.xxx"、"2.xxx"等层级结构
- **建议和说明**：如"建议发问方式："等指导性内容

### 3. 分段边界
- **起始点**：每个FAQ从问题开始
- **结束点**：到下一个问题开始之前结束，或文档结束
- **空字符串处理**：通常是分隔符，包含在前一个FAQ中（除非是文档开头的标题分隔）
- **标题处理**：文档总标题（如"社保知识问答"）如果独立存在，可考虑排除或单独处理

### 4. 特殊情况处理
- **标题排除**：纯标题性内容（如"XXX知识问答"）不计入具体的问答分段
- **连续性保证**：即使遇到格式不规范的情况，也要确保所有index被分配
- **语义完整性**：优先保证问答对的语义完整，避免将答案中的疑问句误判为新问题

## 输出格式
只输出index区间的二维数组，格式：[[起始index, 结束index], [起始index, 结束index], ...]
- 索引使用数字格式（将字符串索引转换为数字）
- 起始和结束索引都是包含性的（inclusive）
- 确保覆盖所有输入的index

### 示例1（标准问答格式）
**输入：**
```json
[
   {"index": "0", "text": "问：加油后如何开具发票？"},
   {"index": "1", "text": "答：需要先判断客户的加油方式，针对性解答"},
   {"index": "2", "text": "建议发问方式：请问您是在哪个省份加的油？"},
   {"index": "3", "text": "（1）石化钱包：您好，您可以打开易捷加油APP..."},
   {"index": "4", "text": ""},
   {"index": "5", "text": "问：无法开具加油发票如何处理？"},
   {"index": "6", "text": "答：需要先判断客户的开票渠道，针对性解答"}
]
```
**输出：** `[[0,4],[5,6]]`

### 示例2（数字编号格式）
**输入：**
```json
[
  {"index": "0", "text": "社保知识问答"},
  {"index": "1", "text": "1. 什么是社会保险？主要包括哪些项目？"},
  {"index": "2", "text": "社会保险是劳动者由于年老..."},
  {"index": "3", "text": "社会保险主要包括养老保险..."},
  {"index": "4", "text": "2.社会保险与商业保险的区别？"},
  {"index": "5", "text": "社会保险与商业保险是两种不同性质的保险..."}
]
```
**输出：** `[[1,3],[4,5]]`

## 注意事项
1. **完整性检查**：确保每个分段都包含完整的问答对
2. **索引处理**：index使用字符串格式，需要转换为数字进行比较和输出
3. **问题识别精度**：仔细识别问题的开始，避免将答案中的疑问句误判为新问题
4. **格式容错**：如果遇到格式不规范的情况，优先保证语义的完整性
5. **覆盖完整性**：所有index必须被分配到某个分段中，不允许任何index被遗漏
6. **边界处理**：特别注意文档开头的标题和文档结尾的处理

请按照上述规则对输入的FAQ文档进行分段，只返回分段结果的二维数组。
