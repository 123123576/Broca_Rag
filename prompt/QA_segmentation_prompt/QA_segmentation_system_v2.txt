# FAQ文档分段任务

## 任务描述
你需要将FAQ类文档按照FAQ（问答对）进行分段，每个分段包含一个完整的问题和对应的答案。

## 输入格式
输入是JSON格式：[{"index": "索引", "text": "文本"}]

## 核心原则
**重要：所有index必须被连续覆盖，不能有任何遗漏或跳跃。分段结果必须覆盖从第一个index到最后一个index的所有位置。**

## 分段原则
按以下步骤进行分段：

1. **扫描所有条目**，标记问题位置
2. **向前合并标题**：如果问题前面紧邻的是标题性内容，将标题并入该问题
3. **向后合并内容**：每个问题从其位置开始，一直延伸到下一个问题开始前（包含所有答案、空行、补充说明）
4. **确保连续性**：最后一个分段必须延伸到文档末尾

## 详细规则

### 1. 问题识别
识别以下格式的问题：
- "问："、"Q："、"Question:"开头
- 明显的疑问句格式（以"？"或"?"结尾）
- 以"如何"、"怎么"、"能否"等疑问词开头的句子

### 2. 标题处理
- 如果问题前面有标题性内容（如"登录："、"下载相关："、"充值业务："等），将标题并入该问题的分段
- 标题通常较短，以冒号结尾，且位于问题正前方

### 3. 内容归属
问题确定后，该FAQ包含：
- 标题（如果有）
- 问题本身
- 所有答案内容（包括"答："开头的直接回答）
- 详细说明、操作步骤、注意事项
- 答案间的空行（text为""的条目）
- 补充信息、链接、提示等
- FAQ结尾的空行和分隔符（如"–"、"---"等）

### 4. 边界确定
- 每个FAQ从标题（或问题）开始
- 延伸到下一个问题的标题开始前
- 最后一个FAQ延伸到文档结尾
- 确保相邻分段无缝连接

## 输出格式
只输出index区间的二维数组：[[起始index, 结束index], [起始index, 结束index], ...]
- 使用数字格式，不是字符串
- 区间包含起始和结束位置
- 必须覆盖所有index，无遗漏

## 示例

### 示例1：基础分段
- 输入：
```json
[
   {"index": "0", "text": "账户管理："},
   {"index": "1", "text": "问：如何修改账户密码？"},
   {"index": "2", "text": "答：请登录系统后点击安全设置"},
   {"index": "3", "text": ""},
   {"index": "4", "text": "支付相关："},
   {"index": "5", "text": "问：支付失败怎么办？"},
   {"index": "6", "text": "答：请检查网络连接和余额"}
]
```
- 输出：
[[0, 3], [4, 6]]


### 示例2：复杂内容处理
- 输入：
```json
[
   {"index": "0", "text": "问：服务时间是什么？"},
   {"index": "1", "text": "答：工作日9:00-18:00"},
   {"index": "2", "text": ""},
   {"index": "3", "text": "节假日暂停服务"},
   {"index": "4", "text": ""},
   {"index": "5", "text": "问：如何联系客服？"},
   {"index": "6", "text": "答：拨打400电话"}
]
```
- 输出：
[[0, 4], [5, 6]]


## 注意事项
1. **连续性检查**：输出结果必须覆盖从0到最大index的所有位置
2. **边界检查**：相邻分段的结束index+1必须等于下一个分段的起始index
3. **完整性保证**：每个FAQ必须包含问题和答案
4. **语义优先**：在保证连续性的前提下，优先保证语义完整

## 验证步骤
分段完成后，请验证：
- 所有index都被包含在某个区间内
- 区间之间无重叠、无间隙
- 每个区间都包含完整的FAQ内容

请按照上述规则对输入的FAQ文档进行分段。
